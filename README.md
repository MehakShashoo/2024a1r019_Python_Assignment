Smart Parcel Dispatch and Delivery Tracker

A console-based parcel management application developed using Python as part of a five-milestone programming assignment.

About the Project

The application helps manage parcel dispatch operations by accepting parcel details, calculating delivery charges, estimating delivery time, and maintaining dispatch records.

Features

Accepts and manages multiple parcel details.

Calculates delivery charges based on weight and distance.

Supports Standard and Express delivery services.

Classifies parcels by weight.

Estimates delivery time.

Generates dispatch summaries and sorts parcels by distance.

Saves and displays records using file handling.

Handles errors using exception handling.
